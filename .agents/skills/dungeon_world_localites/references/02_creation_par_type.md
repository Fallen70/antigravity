# 🏙️ Création de localité par type

Ce guide récapitule les règles de création pas-à-pas pour les 4 types de localités de **Dungeon World** : **Village**, **Bourg**, **Forteresse** et **Ville**.

---

## 🏡 1. Créer un Village

Un village est une petite communauté (quelques dizaines à une centaine d'habitants), isolée, vivant de l'exploitation directe des ressources environnantes.

### Marqueurs par défaut
* **Pauvre**, **Stable**, **Milice**, **Ressource (au choix)**, **Serment (à une autre localité)**.

### Origine / Caractéristique (Choisissez 1 si le village fait partie d'un royaume/empire)
1. **Naturellement défendu** : *Sûr*, *-Défenses*
2. **Ressources abondantes** : *+Prospérité*, *Ressources (au choix)*, *Inimitié (au choix)*
3. **Sous la protection d'une autre localité** : *Serment*, *+Défenses*
4. **Sur une route principale** : *Commerce (au choix)*, *+Prospérité*
5. **Autour de la tour d'un magicien** : *Personnage (le mage)*, *Plaie (créatures des arcanes)*
6. **Site d'importance religieuse** : *Religion*, *Historique (au choix)*

### Problème (Choisissez 1)
1. **Terres arides ou incultes** : *Besoin (nourriture)*
2. **Dédié à une divinité rivale** : *Culte (cette divinité)*, *Inimitié (localité d'une autre divinité)*
3. **Bataille récente** : *-Population*, *-Prospérité*, (si défaite finale : *-Défenses*)
4. **Monstres menaçants** : *Plaie (ces monstres)*, *Besoin (aventuriers)*
5. **Absorbe un autre village** : *+Population*, *Crime*
6. **Paumé ou hostile** : *-Prospérité*, *Nains* ou *Elfes*

---

## 🏘️ 2. Créer un Bourg

Un bourg compte environ une centaine d'habitants permanents, développé autour d'un point de passage, moulin, auberge ou comptoir commercial.

### Marqueurs par défaut
* **Moyenne**, **Stable**, **Guet**, **Commerce (deux localités au choix)**.

### Origine / Caractéristique (Choisissez 1 si le bourg fait du commerce)
1. **En plein essor** : *En plein essor*, *Crime*
2. **Au carrefour de routes** : *Marché*, *+Prospérité*
3. **Défendu par une autre localité** : *Serment (cette localité)*, *+Défenses*
4. **Construit autour d'une église** : *Puissance (religieuse)*
5. **Construit autour d'un métier** : *Artisanat (au choix)*, *Ressource (nécessaire à cet artisanat)*
6. **Construit autour d'un poste militaire** : *+Défenses*

### Problème (Choisissez 1)
1. **Pénurie liée à sa croissance** : *Besoin (ressource cruciale)*, *Commerce (localité avec cette ressource)*
2. **Offre une défense aux voisins** : *Serment (au choix)*, *-Défenses*
3. **Abrite un hors-la-loi célèbre** : *Personnage (le bandit)*, *Inimitié (lieu des crimes)*
4. **Monopole sur un bien ou service** : *Exotique (bien/service)*, *Inimitié (localité concurrente)*
5. **Frappé par une maladie** : *-Population*
6. **Lieu de rencontre populaire** : *+Population*, *Crime*

---

## 🏰 3. Créer une Forteresse

Construite spécifiquement pour la défense d'un point stratégique (col, rivière, mine, frontière). Entre 100 et 1 000 habitants endurcis.

### Marqueurs par défaut
* **Pauvre**, **En déclin**, **Garde**, **Besoin (fournitures)**, **Commerce (consommables)**, **Serment (au choix)**.

### Origine / Caractéristique (Choisissez 1 si allégeance établie)
1. **Appartient à une famille noble** : *+Prospérité*, *Puissance (politique)*
2. **Dirigée par un commandant habile** : *Personnage (le commandant)*, *+Défenses*
3. **Surveille une route commerciale** : *+Prospérité*, *Guilde (commerce)*
4. **Entraîne des troupes spéciales** : *Magie*, *-Population*
5. **Terres fertiles aux alentours** : *Supprimer Besoin (fournitures)*
6. **Sur une frontière instable** : *+Défenses*, *Inimitié (l'autre côté)*

### Problème (Choisissez 1)
1. **Position naturelle ultra-défendable** : *Sûr*, *-Population*
2. **Appartenait autrefois à une autre puissance** : *Inimitié (localités de cette puissance)*
3. **Refuge de brigands** : *Crime*
4. **Construite contre une menace spécifique** : *Plaie (cette menace)*
5. **Guerre sanglante dans le passé** : *Historique (bataille)*, *Plaie (esprits sans repos)*
6. **Recrues médiocres ou indisciplinées** : *Besoin (recrues qualifiées)*

---

## 🏛️ 4. Créer une Ville

Métropole ou grand centre urbain. Carrefour culturel et commercial brassant de nombreuses populations.

### Marqueurs par défaut
* **Moyenne**, **Stable**, **Garde**, **Marché**, **Guilde (au choix)**, **Serments (au moins 2 localités, ex. un bourg et une forteresse)**.

### Origine / Caractéristique (Choisissez 1 si alliance et commerce solides)
1. **Défenses permanentes (remparts, bastions)** : *+Défenses*, *Serment (au choix)*
2. **Dominée par un autocrate/seigneur** : *Personnage (le dirigeant)*, *Puissance (politique)*
3. **Multiculturelle** : *Nains* ou *Elfes* (ou les deux)
4. **Plaque tournante du commerce** : *Commerce (toutes les localités proches)*, *+Prospérité*
5. **Ancienne, bâtie sur ses propres ruines** : *Historique (au choix)*, *Religion*
6. **Centre de savoir et d'arts** : *Magie*, *Artisanat (au choix)*, *Puissance (magique)*

### Problème (Choisissez 1)
1. **Surpopulation & crise d'approvisionnement** : *+Population*, *Besoin (nourriture)*
2. **Visées expansionnistes/impérialistes** : *Inimitié (localités proches)*, *+Défenses*
3. **Théocratie autoritaire** : *-Défenses*, *Puissance (religieuse)*
4. **Gouvernée par le peuple / Démocratie houleuse** : *-Défenses*, *+Population*
5. **Défenses surnaturelles capricieuses** : *+Défenses*, *Plaie (créatures liées)*
6. **Bâtie sur un nœud d'énergie/pouvoir** : *Magie*, *Personnage (le gardien)*, *Plaie (créatures arcaniques)*
