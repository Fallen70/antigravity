# Guide du Compte à rebours (Countdown)

Le compte à rebours décrit les événements qui se dérouleront de manière inéluctable si les Chasseurs n'interviennent pas.

| Étape | Description / Signes typiques |
| --- | --- |
| **Jour (Day)** | Le premier incident ou signe de l'activité du monstre. Souvent discret. |
| **Pénombre (Shadows)** | Le monstre commence à chasser activement ou à préparer son plan. |
| **Coucher de soleil (Sunset)** | Le danger devient évident. Première victime publique ou événement étrange majeur. |
| **Crépuscule (Dusk)** | La situation échappe au contrôle des autorités locales. Les monstres/sbires attaquent ouvertement. |
| **Tombée de la nuit (Nightfall)** | La dernière chance pour les Chasseurs d'agir avant la catastrophe finale. |
| **Minuit (Midnight)** | Le plan du monstre réussit. Destruction massive, invocation réussie, ou perte totale de contrôle. |
