# Types de Menaces et Motivations (Monster of the Week)

## Monstres (Monsters)
*   **Bête (Beast)** : motivation : tout détruire.
*   **Dévoreur (Devourer)** : motivation : tout consommer.
*   **Reproducteur (Breeder)** : motivation : se reproduire et infester.
*   **Collectionneur (Collector)** : motivation : voler et accumuler.
*   **Destructeur (Destroyer)** : motivation : provoquer la fin du monde.
*   **Bourreau (Executioner)** : motivation : punir les coupables.
*   **Parasite (Parasite)** : motivation : infester et contrôler.
*   **Reine (Queen)** : motivation : soumettre et régner.
*   **Sorcier (Sorcerer)** : motivation : canaliser de la magie maléfique.
*   **Tentateur** : motivation : pousser les gens à faire le mal.
*   **Tortionnaire (Torturer)** : motivation : blesser et terrifier.
*   **Perturbateur (Trickster)** : motivation : semer le chaos.

## Sbires (Minions)
*   **Assassin (Assassin)** : motivation : éliminer les Chasseurs.
*   **Brute (Brute)** : motivation : intimider et attaquer par la force brute.
*   **Adepte / Sectateur (Cultist)** : motivation : vénérer, sauver ou aider le monstre.
*   **Sentinelle (Guardian)** : motivation : barrer le passage ou protéger une zone/un objet.
*   **Éclaireur (Scout)** : motivation : surveiller, traquer et rapporter des informations.
*   **Voleur (Thief)** : motivation : dérober des ressources ou des artefacts et s'enfuir.
*   **Bras droit (Right Hand)** : motivation : soutenir le monstre ou exécuter ses ordres complexes.
*   **Fléau (Plague)** : motivation : submerger et détruire.
*   **Renfield (Renfield)** : motivation : pousser les victimes vers le monstre.
*   **Traître (Traitor)** : motivation : trahir les gens.

## Lieux (Locations)
*   **Carrefour** : motivation : rassembler les gens et les choses.
*   **Piège mortel** : motivation : blesser les intrus.
*   **Antre** : motivation : abriter les monstres.
*   **Forteresse** : motivation : empêcher toute entrée.
*   **Portail infernal** : motivation : engendrer le mal.
*   **Plaque tournante** : motivation : révéler des informations.
*   **Laboratoire** : motivation : créer l'étrange.
*   **Dédale** : motivation : embrouiller et séparer.
*   **Prison** : motivation : contraindre et empêcher toute sortie.
*   **Planque** : motivation : accueillir les choses cachées.

## Innocents (Bystanders)
*   **Fouineur (Busybody)** : motivation : se mêler de ce qui ne le regarde pas.
*   **Détective (Detective)** : motivation : trouver une explication.
*   **Commère (Gossip)** : motivation : bavarder et répandre des rumeurs.
*   **Assistant (Helper)** : motivation : rejoindre la chasse.
*   **Innocent (Innocent)** : motivation : faire une bonne action / survivre.
*   **Officiel (Official)** : motivation : être méfiant.
*   **Sceptique (Skeptic)** : motivation : nier les explications surnaturelles.
*   **Victime (Victim)** : motivation : se mettre en danger.
*   **Témoin (Witness)** : motivation : révéler des informations.
