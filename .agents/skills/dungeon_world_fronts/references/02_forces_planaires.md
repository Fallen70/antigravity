# 2️⃣ Forces planaires

**Définition** : entités d’un plan supérieur ou inférieur (dieux, démons, êtres célestes, esprits).  
**But typique** : *propager leur influence*, *ouvrir un passage* entre les plans, *juger* ou *détruire*.  
**Exemples** : Dieu (ex. : Lune), Prince démon, Chœur angélique, Instrument de la loi.  
**Acteurs courants** : avatar, serviteurs planaires, cultistes, prophètes, créatures mineures.  

**Actions MJ** :
- **Prophétiser** : annoncer une vision ou une malédiction.
- **Bénir / maudire** : accorder une grâce ou une malédiction.
- **Déclencher un événement céleste** : tempête, éclair, porte dimensionnelle.
- **Imposer un jugement** : test moral, sacrifice requis.
- **Manipuler la réalité** : altérer gravité, temps ou météo.

**Conseils de conception** :
- Leur **nature** doit être distincte de celle des mortels.
- Pensez à la **portée** (locale, régionale, mondiale).
- Ajoutez une **action sur‑mesure** liée à leur pouvoir (ex. : ouverture d’un portail dimensionnel).
