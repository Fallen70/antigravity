# 1️⃣ Organisations ambitieuses

**Définition** : groupes structurés qui poursuivent un objectif à long terme (politique, religieux, criminel, social).  
**But typique** : *obtenir*, *protéger* ou *imposer* un pouvoir, une doctrine ou un statut.  
**Exemples** : Cabale, Gouvernement corrompu, Culte secret, Guilde de voleurs, Ordre religieux.  
**Acteurs courants** : leader charismatique, membres influents, agents infiltrés, sbires.  

**Actions MJ (extraits du manuel)** :
- **Infiltrer** : placer des agents dans une organisation ennemie.
- **Manipuler la loi** : changer une règle ou une politique.
- **Recruter / acheter** : gagner un allié important.
- **Imposer des exigences** : exiger un tribut ou une faveur.
- **Déclencher un rituel** : actions spécifiques à leur mission (ex. : ouverture d’un portail).

**Conseils de conception** :
- Décrivez clairement **qui** veut quoi et **pourquoi**.
- Définissez le **réseau** d’influence (alliés, rivaux).
- Indiquez une ou deux **actions sur‑mesure** spécifiques qui peuvent être déclenchées par les PJ.
